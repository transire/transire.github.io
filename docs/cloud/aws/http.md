# AWS HTTP Integration (API Gateway)

## Overview

Transire deploys HTTP handlers to AWS Lambda behind API Gateway (HTTP API). This integration provides:

- **Serverless scaling** - Automatic scale from zero to thousands of requests
- **Pay-per-use** - Only pay for actual invocations
- **AWS integration** - Native access to AWS services
- **Global availability** - Deploy to any AWS region

The same HTTP handler code runs identically in local mode and AWS Lambda—no cloud-specific changes required.

## Architecture

```
Client Request
    ↓
API Gateway (HTTP API)
    ↓
Lambda Function (HTTP Handler)
    ↓
Your Handler Code
    ↓
Response → API Gateway → Client
```

### Key Components

| Component | Purpose | Configuration |
|-----------|---------|---------------|
| **API Gateway** | HTTP endpoint, routing | Generated by Transire |
| **Lambda Function** | Runs your handler code | One per HTTP handler |
| **IAM Role** | Permissions (least-privilege) | Auto-generated |
| **CloudWatch Logs** | Logging and monitoring | Automatic retention |

## Request Flow

### 1. API Gateway Receives Request

API Gateway receives the HTTP request and creates an event:

```json
{
  "version": "2.0",
  "routeKey": "GET /users/{id}",
  "rawPath": "/users/42",
  "rawQueryString": "format=json&include=profile",
  "headers": {
    "content-type": "application/json",
    "x-forwarded-for": "203.0.113.1"
  },
  "requestContext": {
    "requestId": "abc123",
    "http": {
      "method": "GET",
      "path": "/users/42",
      "sourceIp": "203.0.113.1"
    }
  },
  "body": null,
  "isBase64Encoded": false
}
```

### 2. Lambda Invokes Cloud Handler

Transire's AWS cloud handler receives the API Gateway event and translates it to `transire.HTTPRequest`:

```go
// Internal: AWS cloud handler (non-user-facing)
func HandleAPIGatewayEvent(ctx context.Context, event events.APIGatewayV2HTTPRequest) (events.APIGatewayV2HTTPResponse, error) {
    // Decode base64 body if needed
    body := event.Body
    if event.IsBase64Encoded {
        decoded, _ := base64.StdEncoding.DecodeString(body)
        body = string(decoded)
    }

    // Parse multi-value query params
    queryParams := parseQueryString(event.RawQueryString)

    // Create transire.HTTPRequest
    req := &transire.HTTPRequest{
        Method:      event.RequestContext.HTTP.Method,
        Path:        event.RawPath,
        Headers:     event.Headers,
        QueryParams: queryParams,
        Body:        []byte(body),
        PathParams:  extractPathParams(event),
    }

    // Route through Chi to find registered handler
    resp, err := router.ServeHTTP(ctx, req)
    if err != nil {
        return errorResponse(err), nil
    }

    // Translate transire.HTTPResponse → API Gateway response
    return events.APIGatewayV2HTTPResponse{
        StatusCode: resp.StatusCode,
        Headers:    resp.Headers,
        Body:       string(resp.Body),
    }, nil
}
```

### 3. Your Handler Executes

Your handler receives the standard `transire.HTTPRequest`:

```go
func getUser(w http.ResponseWriter, r *http.Request) {
    // Extract path parameter
    userID := transire.URLParam(r, "id")

    // Business logic (same code as local!)
    user, err := db.GetUser(r.Context(), userID)
    if err != nil {
        http.Error(w, "User not found", http.StatusNotFound)
        return
    }

    // Return JSON
    w.Header().Set("Content-Type", "application/json")
    json.NewEncoder(w).Encode(user)
}
```

### 4. Response Returns to Client

Transire translates your handler's response back to API Gateway format, which returns it to the client.

## Deployment

### Generated Resources

When you run `transire deploy`, the following AWS resources are created for each HTTP handler:

#### Lambda Function
```hcl
resource "aws_lambda_function" "get_users_id" {
  function_name = "${var.service_name}-get-users-id"
  role         = aws_iam_role.lambda_exec.arn

  # From transire.yaml deploy config
  runtime       = "provided.al2023"
  architectures = ["arm64"]
  memory_size   = 512
  timeout       = 30

  # Handler selection
  environment {
    variables = {
      TRANSIRE_HANDLER = "GET /users/{id}"
    }
  }

  # Deployment artifact
  filename         = "dist/http-handler.zip"
  source_code_hash = filebase64sha256("dist/http-handler.zip")
}
```

#### API Gateway Integration
```hcl
resource "aws_apigatewayv2_integration" "get_users_id" {
  api_id           = aws_apigatewayv2_api.main.id
  integration_type = "AWS_PROXY"
  integration_uri  = aws_lambda_function.get_users_id.invoke_arn

  payload_format_version = "2.0"
}

resource "aws_apigatewayv2_route" "get_users_id" {
  api_id    = aws_apigatewayv2_api.main.id
  route_key = "GET /users/{id}"
  target    = "integrations/${aws_apigatewayv2_integration.get_users_id.id}"
}
```

#### IAM Permissions
```hcl
resource "aws_iam_role_policy" "lambda_exec" {
  role = aws_iam_role.lambda_exec.id

  policy = jsonencode({
    Version = "2012-10-17"
    Statement = [
      {
        Effect = "Allow"
        Action = [
          "logs:CreateLogGroup",
          "logs:CreateLogStream",
          "logs:PutLogEvents"
        ]
        Resource = "arn:aws:logs:*:*:*"
      }
    ]
  })
}
```

### Configuration

Control Lambda settings via `transire.yaml`:

```yaml
deploy:
  arch: arm64              # or amd64
  memory: 512              # MB (128-10240)
  timeout: 30              # seconds (1-900)

  # Per-handler overrides
  handlers:
    "GET /users/{id}":
      memory: 256          # Lightweight read
      timeout: 5

    "POST /users/{id}/process":
      memory: 1024         # Heavy processing
      timeout: 60
```

## Request/Response Translation

### Path Parameters

API Gateway extracts path params automatically. Access via Chi:

```go
func getUser(w http.ResponseWriter, r *http.Request) {
    userID := transire.URLParam(r, "id")    // From /users/{id}
    // Use userID...
}
```

### Query Parameters

Multi-value query params are preserved:

```
GET /search?tag=go&tag=cloud&limit=10

r.URL.Query().Get("limit")      → "10"
r.URL.Query()["tag"]            → ["go", "cloud"]
```

### Headers

All headers are forwarded. Common AWS headers:

```go
func handler(w http.ResponseWriter, r *http.Request) {
    // Original client IP (behind API Gateway)
    clientIP := r.Header.Get("X-Forwarded-For")

    // API Gateway request ID
    requestID := r.Header.Get("X-Amzn-Trace-Id")

    // CloudFront headers (if using CDN)
    country := r.Header.Get("CloudFront-Viewer-Country")
}
```

### Request Body

Binary data is automatically decoded:

```go
func uploadImage(w http.ResponseWriter, r *http.Request) {
    // Body is already decoded from base64 (if needed)
    imageData, _ := io.ReadAll(r.Body)
    defer r.Body.Close()

    // Process image...
}
```

### Response Headers

Set any headers—they're forwarded to the client:

```go
func handler(w http.ResponseWriter, r *http.Request) {
    w.Header().Set("Content-Type", "application/json")
    w.Header().Set("Cache-Control", "public, max-age=3600")
    w.Header().Set("X-Custom-Header", "value")

    json.NewEncoder(w).Encode(data)
}
```

## Performance Considerations

### Cold Start Optimization

**Lambda cold starts** occur when a new container initializes. Optimize with:

1. **ARM64 architecture** (faster, cheaper):
```yaml
deploy:
  arch: arm64
```

2. **Right-size memory** (CPU scales with memory):
```yaml
deploy:
  memory: 512  # Balance between cost and performance
```

3. **Minimize dependencies**:
```go
// ❌ Heavy imports in global scope
import (
    "github.com/aws/aws-sdk-go-v2/aws"
    "github.com/aws/aws-sdk-go-v2/config"
    _ "github.com/lib/pq"  // Database driver
)

// ✅ Lazy-load heavy dependencies
var db *sql.DB

func init() {
    // Only if DATABASE_URL is set
    if url := os.Getenv("DATABASE_URL"); url != "" {
        db, _ = sql.Open("postgres", url)
    }
}
```

4. **Use connection pooling** (reuse across invocations):
```go
var (
    dbOnce sync.Once
    db     *sql.DB
)

func getDB() *sql.DB {
    dbOnce.Do(func() {
        db, _ = sql.Open("postgres", os.Getenv("DATABASE_URL"))
        db.SetMaxOpenConns(5)
        db.SetConnMaxLifetime(5 * time.Minute)
    })
    return db
}
```

### Request Limits

API Gateway HTTP API limits:

| Limit | Value |
|-------|-------|
| **Payload size** | 10 MB (request + response) |
| **Timeout** | 30 seconds (API Gateway) |
| **Lambda timeout** | 900 seconds (configurable) |
| **Headers** | 10 KB total |

For larger payloads, use presigned S3 URLs:

```go
func uploadLargeFile(w http.ResponseWriter, r *http.Request) {
    // Generate presigned PUT URL
    url, _ := s3.PresignPutObject(ctx, &s3.PutObjectInput{
        Bucket: aws.String("my-bucket"),
        Key:    aws.String("uploads/file.dat"),
    }, s3.WithPresignExpires(15*time.Minute))

    // Return URL to client
    json.NewEncoder(w).Encode(map[string]string{
        "upload_url": url,
    })
}
```

## Error Handling

### HTTP Errors

Return standard HTTP errors—they're translated correctly:

```go
func handler(w http.ResponseWriter, r *http.Request) {
    if unauthorized {
        http.Error(w, "Unauthorized", http.StatusUnauthorized)
        return
    }

    if notFound {
        http.Error(w, "Not found", http.StatusNotFound)
        return
    }

    if err != nil {
        http.Error(w, "Internal server error", http.StatusInternalServerError)
        return
    }
}
```

### Panic Recovery

Panics are caught and logged:

```go
func handler(w http.ResponseWriter, r *http.Request) {
    defer func() {
        if r := recover(); r != nil {
            log.Printf("Panic recovered: %v\n%s", r, debug.Stack())
            http.Error(w, "Internal server error", http.StatusInternalServerError)
        }
    }()

    // Your code...
}
```

Transire provides automatic panic recovery middleware in cloud mode.

## Logging

### CloudWatch Logs

All output to stdout/stderr goes to CloudWatch Logs:

```go
func handler(w http.ResponseWriter, r *http.Request) {
    log.Printf("Processing request: method=%s path=%s", r.Method, r.URL.Path)
    // Appears in CloudWatch Logs
}
```

**Log group:** `/aws/lambda/{service-name}-{handler-name}`

**Retention:** Configurable (default: 7 days)

### Structured Logging

Use JSON for better querying:

```go
import "encoding/json"

func logEvent(message string, fields map[string]interface{}) {
    entry := map[string]interface{}{
        "timestamp": time.Now().Unix(),
        "message":   message,
    }
    for k, v := range fields {
        entry[k] = v
    }
    json.NewEncoder(os.Stdout).Encode(entry)
}

func handler(w http.ResponseWriter, r *http.Request) {
    logEvent("user_request", map[string]interface{}{
        "user_id": transire.URLParam(r, "id"),
        "method":  r.Method,
        "path":    r.URL.Path,
    })
}
```

## Monitoring

### CloudWatch Metrics

Automatic metrics (per Lambda function):

- **Invocations** - Total requests
- **Duration** - Execution time
- **Errors** - Handler errors
- **Throttles** - Concurrency limit hits

### Custom Metrics

Publish custom metrics to CloudWatch:

```go
import "github.com/aws/aws-sdk-go-v2/service/cloudwatch"

func publishMetric(ctx context.Context, name string, value float64) {
    client := cloudwatch.NewFromConfig(awsCfg)
    client.PutMetricData(ctx, &cloudwatch.PutMetricDataInput{
        Namespace: aws.String("Transire/MyApp"),
        MetricData: []types.MetricDatum{{
            MetricName: aws.String(name),
            Value:      aws.Float64(value),
            Timestamp:  aws.Time(time.Now()),
        }},
    })
}
```

## Troubleshooting

### Issue: Handler not receiving requests

**Check:**
1. API Gateway route is configured:
   ```bash
   aws apigatewayv2 get-routes --api-id <api-id>
   ```

2. Lambda has correct permissions:
   ```bash
   aws lambda get-policy --function-name <function-name>
   ```

3. `TRANSIRE_HANDLER` environment variable matches route:
   ```bash
   aws lambda get-function-configuration --function-name <function-name> \
       --query 'Environment.Variables.TRANSIRE_HANDLER'
   ```

### Issue: 502 Bad Gateway

**Causes:**
- Lambda timeout (exceeds API Gateway 30s limit)
- Lambda out of memory
- Invalid response format

**Check CloudWatch Logs:**
```bash
aws logs tail /aws/lambda/<function-name> --follow
```

### Issue: Cold start latency

**Optimize:**
1. Use ARM64 architecture
2. Reduce deployment package size
3. Enable Lambda SnapStart (Java/.NET only)
4. Provision concurrency for critical endpoints:
   ```yaml
   deploy:
     handlers:
       "GET /users/{id}":
         provisioned_concurrency: 2
   ```

## Cost Optimization

### Pricing Model

- **Requests:** $1.00 per 1M requests
- **Duration:** $0.0000166667 per GB-second (ARM64)
- **Free tier:** 1M requests + 400,000 GB-seconds per month

### Cost Examples

**Scenario: Simple API (128 MB, 100ms avg)**
- 1M requests/month
- 100ms × 128 MB = 12,800 MB-seconds = 12.8 GB-seconds
- Cost: ~$1.00 (requests) + ~$0.00 (duration) = **$1.00/month**

**Scenario: Heavy processing (1 GB, 5s avg)**
- 100K requests/month
- 5s × 1024 MB = 512,000 MB-seconds = 512 GB-seconds
- Cost: ~$0.10 (requests) + ~$0.85 (duration) = **$0.95/month**

### Optimization Tips

1. **Right-size memory** - More memory = more CPU, but higher cost
2. **Use ARM64** - 20% cheaper than x86
3. **Optimize cold starts** - Reduces billed duration
4. **Batch where possible** - Process multiple items per invocation
5. **Set appropriate timeouts** - Don't pay for hung handlers
