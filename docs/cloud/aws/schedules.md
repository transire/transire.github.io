# AWS Schedule Integration (EventBridge)

## Overview

Transire deploys scheduled handlers to AWS Lambda triggered by EventBridge Scheduler. This provides:

- **Cron-based scheduling** - Run at specific times (daily, hourly, etc.)
- **Fixed-rate scheduling** - Run every N minutes/hours
- **No overlapping executions** - One invocation at a time per schedule
- **Serverless** - No always-on servers
- **Automatic retries** - Failed executions retry with backoff

The same scheduled handler code runs identically in local mode and AWS Lambda.

## Architecture

```
EventBridge Scheduler
    ↓
Trigger at scheduled time
    ↓
Lambda Function (Scheduled Handler)
    ↓
Your Handler Code
    ↓
Complete → Wait for next trigger
```

### Key Components

| Component | Purpose | Configuration |
|-----------|---------|---------------|
| **EventBridge Rule** | Schedule trigger | Generated by Transire |
| **Lambda Function** | Runs your handler | One per scheduled handler |
| **IAM Role** | Permissions | Auto-generated |
| **CloudWatch Logs** | Logging and monitoring | Automatic retention |
| **DLQ** | Failed invocations | Optional |

## Scheduling Patterns

### Cron Expressions

Run at specific times using cron syntax:

```go
import "github.com/transire/transire-sdk-go"

func main() {
    app := transire.New()

    // Every day at 2:00 AM UTC
    app.RegisterScheduled("0 2 * * ? *", generateDailyReport)

    // Every Monday at 9:00 AM UTC
    app.RegisterScheduled("0 9 ? * MON *", sendWeeklyNewsletter)

    // Every 15 minutes
    app.RegisterScheduled("0/15 * * * ? *", checkSystemHealth)

    // First day of month at midnight
    app.RegisterScheduled("0 0 1 * ? *", monthlyCleanup)

    app.Run()
}
```

**Cron Format:** `minute hour day-of-month month day-of-week year`

**Examples:**

| Expression | Meaning |
|------------|---------|
| `0 2 * * ? *` | Daily at 2:00 AM UTC |
| `0 */6 * * ? *` | Every 6 hours |
| `0 9 ? * MON *` | Mondays at 9:00 AM UTC |
| `0 0 1 * ? *` | First of month at midnight |
| `0 0 ? * MON-FRI *` | Weekdays at midnight |

### Fixed Rate

Run every N minutes/hours:

```go
import "github.com/transire/transire-sdk-go"

func main() {
    app := transire.New()

    // Every 5 minutes
    app.ScheduledRate("5m", processQueue)

    // Every hour
    app.ScheduledRate("1h", aggregateMetrics)

    // Every 30 seconds (minimum)
    app.ScheduledRate("30s", healthCheck)

    app.Run()
}
```

**Rate Format:**
- `Ns` - Seconds (N ≥ 30)
- `Nm` - Minutes (1-60)
- `Nh` - Hours (1-24)

## Handler Implementation

### Basic Handler

```go
func generateDailyReport(ctx context.Context) error {
    log.Println("Starting daily report generation...")

    // Fetch data
    orders, err := db.GetOrdersForDate(ctx, time.Now().AddDate(0, 0, -1))
    if err != nil {
        return fmt.Errorf("failed to fetch orders: %w", err)
    }

    // Generate report
    report := generateReport(orders)

    // Send to S3
    err = uploadToS3(ctx, report)
    if err != nil {
        return fmt.Errorf("failed to upload report: %w", err)
    }

    log.Println("Daily report generated successfully")
    return nil
}
```

### With Timeout

Respect context deadline:

```go
func monthlyCleanup(ctx context.Context) error {
    // Check if we're about to timeout
    deadline, ok := ctx.Deadline()
    if ok && time.Until(deadline) < 5*time.Second {
        return errors.New("not enough time remaining")
    }

    // Long-running work
    for _, table := range []string{"logs", "temp_data", "cache"} {
        select {
        case <-ctx.Done():
            return ctx.Err()  // Timeout or cancellation
        default:
            if err := cleanTable(ctx, table); err != nil {
                return fmt.Errorf("failed to clean %s: %w", table, err)
            }
        }
    }

    return nil
}
```

### With Idempotency

Ensure safe retries:

```go
func generateDailyReport(ctx context.Context) error {
    // Generate deterministic key
    reportDate := time.Now().UTC().Format("2006-01-02")
    reportKey := fmt.Sprintf("reports/%s/daily.pdf", reportDate)

    // Check if already generated
    exists, err := s3.ObjectExists(ctx, reportKey)
    if err != nil {
        return err
    }
    if exists {
        log.Printf("Report for %s already exists, skipping", reportDate)
        return nil
    }

    // Generate and upload (idempotent)
    report := generateReport(reportDate)
    return uploadToS3(ctx, reportKey, report)
}
```

## Deployment

### Generated Resources

When you run `transire deploy`:

#### EventBridge Rule (Cron)
```hcl
resource "aws_cloudwatch_event_rule" "generate_daily_report" {
  name                = "${var.service_name}-generate-daily-report"
  description         = "Trigger daily report generation"
  schedule_expression = "cron(0 2 * * ? *)"  # Daily at 2:00 AM UTC
  is_enabled          = true
}
```

#### EventBridge Rule (Fixed Rate)
```hcl
resource "aws_cloudwatch_event_rule" "process_queue" {
  name                = "${var.service_name}-process-queue"
  description         = "Process queue every 5 minutes"
  schedule_expression = "rate(5 minutes)"
  is_enabled          = true
}
```

#### Lambda Function
```hcl
resource "aws_lambda_function" "generate_daily_report" {
  function_name = "${var.service_name}-generate-daily-report"
  role         = aws_iam_role.lambda_exec.arn

  runtime       = "provided.al2023"
  architectures = ["arm64"]
  memory_size   = 512
  timeout       = 300  # 5 minutes default

  environment {
    variables = {
      TRANSIRE_HANDLER = "schedule:generate-daily-report"
    }
  }

  filename         = "dist/schedule-handler.zip"
  source_code_hash = filebase64sha256("dist/schedule-handler.zip")
}
```

#### Lambda Target
```hcl
resource "aws_cloudwatch_event_target" "generate_daily_report" {
  rule      = aws_cloudwatch_event_rule.generate_daily_report.name
  target_id = "lambda"
  arn       = aws_lambda_function.generate_daily_report.arn

  # Retry configuration
  retry_policy {
    maximum_retry_attempts = 2
    maximum_event_age_in_seconds = 3600  # 1 hour
  }

  # Optional: Dead Letter Queue
  dead_letter_config {
    arn = aws_sqs_queue.schedule_dlq.arn
  }
}
```

### Configuration

Control scheduled handler behavior via `transire.yaml`:

```yaml
schedules:
  generate-daily-report:
    timeout: 300        # 5 minutes (default)
    memory: 1024        # MB
    retry_attempts: 2   # EventBridge retries
    enabled: true       # Enable/disable schedule

  process-queue:
    timeout: 60
    memory: 512
    enabled: false      # Temporarily disable
```

## Non-Overlapping Execution

### Built-in Prevention

**Local mode:** Transire blocks overlapping executions automatically.

**AWS mode:** EventBridge ensures one invocation at a time per rule.

**Example:**

```go
// Schedule: Every 5 minutes
// Execution takes 7 minutes

app.ScheduledRate("5m", slowTask)

// Timeline:
// 00:00 - Trigger 1 starts
// 00:05 - Trigger 2 blocked (Trigger 1 still running)
// 00:07 - Trigger 1 completes
// 00:10 - Trigger 3 starts
// 00:15 - Trigger 4 blocked (Trigger 3 still running)
```

### Manual Locking

For distributed coordination (multiple services):

```go
import "github.com/aws/aws-sdk-go-v2/service/dynamodb"

func generateDailyReport(ctx context.Context) error {
    lockKey := "daily-report-lock"

    // Try to acquire lock
    acquired, err := acquireLock(ctx, lockKey, 10*time.Minute)
    if err != nil {
        return err
    }
    if !acquired {
        log.Println("Another instance is running, skipping")
        return nil
    }
    defer releaseLock(ctx, lockKey)

    // Do work...
    return nil
}

func acquireLock(ctx context.Context, key string, ttl time.Duration) (bool, error) {
    client := dynamodb.NewFromConfig(awsCfg)
    _, err := client.PutItem(ctx, &dynamodb.PutItemInput{
        TableName: aws.String("locks"),
        Item: map[string]types.AttributeValue{
            "lock_key": &types.AttributeValueMemberS{Value: key},
            "expires":  &types.AttributeValueMemberN{Value: fmt.Sprintf("%d", time.Now().Add(ttl).Unix())},
        },
        ConditionExpression: aws.String("attribute_not_exists(lock_key) OR expires < :now"),
        ExpressionAttributeValues: map[string]types.AttributeValue{
            ":now": &types.AttributeValueMemberN{Value: fmt.Sprintf("%d", time.Now().Unix())},
        },
    })

    if err != nil {
        var ccf *types.ConditionalCheckFailedException
        if errors.As(err, &ccf) {
            return false, nil  // Lock held by another instance
        }
        return false, err
    }

    return true, nil
}
```

## Error Handling

### Retries

Failed executions retry automatically:

```go
func processData(ctx context.Context) error {
    // Transient error → retries (up to retry_attempts)
    data, err := fetchFromAPI(ctx)
    if err != nil {
        return fmt.Errorf("API unavailable: %w", err)
    }

    // Process...
    return nil
}
```

**Retry behavior:**
- EventBridge retries up to `retry_attempts` (default: 2)
- Exponential backoff between retries
- After max retries → DLQ (if configured)

### Dead Letter Queue

Capture persistently failing invocations:

```yaml
schedules:
  generate-daily-report:
    dlq: true  # Create DLQ for this schedule
```

**Generated resources:**

```hcl
resource "aws_sqs_queue" "schedule_dlq" {
  name                      = "${var.service_name}-schedule-dlq"
  message_retention_seconds = 1209600  # 14 days
}

resource "aws_cloudwatch_event_target" "generate_daily_report" {
  rule = aws_cloudwatch_event_rule.generate_daily_report.name
  arn  = aws_lambda_function.generate_daily_report.arn

  dead_letter_config {
    arn = aws_sqs_queue.schedule_dlq.arn
  }
}
```

**Monitor DLQ:**

```hcl
resource "aws_cloudwatch_metric_alarm" "schedule_dlq" {
```

## Common Patterns

### Daily Aggregation

```go
func dailyAggregation(ctx context.Context) error {
    yesterday := time.Now().UTC().AddDate(0, 0, -1)
    startOfDay := time.Date(yesterday.Year(), yesterday.Month(), yesterday.Day(), 0, 0, 0, 0, time.UTC)
    endOfDay := startOfDay.Add(24 * time.Hour)

    // Aggregate metrics for previous day
    metrics, err := db.AggregateMetrics(ctx, startOfDay, endOfDay)
    if err != nil {
        return err
    }

    // Store aggregated data
    return db.SaveDailyMetrics(ctx, yesterday, metrics)
}
```

### Data Cleanup

```go
func cleanupOldData(ctx context.Context) error {
    cutoff := time.Now().AddDate(0, 0, -90)  // 90 days old

    // Delete in batches to avoid timeouts
    for {
        deleted, err := db.DeleteOldRecords(ctx, cutoff, 1000)
        if err != nil {
            return err
        }

        if deleted == 0 {
            break
        }

        log.Printf("Deleted %d records", deleted)

        // Check context deadline
        select {
        case <-ctx.Done():
            return ctx.Err()
        default:
            time.Sleep(100 * time.Millisecond)
        }
    }

    return nil
}
```

### Report Generation

```go
func generateWeeklyReport(ctx context.Context) error {
    // Calculate last week's date range
    now := time.Now().UTC()
    lastWeek := now.AddDate(0, 0, -7)
    startOfWeek := lastWeek.AddDate(0, 0, -int(lastWeek.Weekday()))

    // Generate report
    report, err := reports.Generate(ctx, reports.Config{
        Type:      "weekly",
        StartDate: startOfWeek,
        EndDate:   startOfWeek.AddDate(0, 0, 7),
    })
    if err != nil {
        return err
    }

    // Upload to S3
    key := fmt.Sprintf("reports/weekly/%s.pdf", startOfWeek.Format("2006-01-02"))
    if err := s3.Upload(ctx, key, report); err != nil {
        return err
    }

    // Send notification
    return notifications.Send(ctx, notifications.Message{
        Subject: "Weekly Report Ready",
        Body:    fmt.Sprintf("Report available at: %s", key),
        To:      []string{"team@example.com"},
    })
}
```

### Health Check

```go
func healthCheck(ctx context.Context) error {
    checks := []struct {
        name string
        fn   func(context.Context) error
    }{
        {"database", checkDatabase},
        {"redis", checkRedis},
        {"external-api", checkExternalAPI},
    }

    var failed []string
    for _, check := range checks {
        if err := check.fn(ctx); err != nil {
            log.Printf("Health check failed: %s - %v", check.name, err)
            failed = append(failed, check.name)
        }
    }

    if len(failed) > 0 {
        // Send alert
        alert := fmt.Sprintf("Health checks failed: %s", strings.Join(failed, ", "))
        notifications.SendAlert(ctx, alert)
        return errors.New(alert)
    }

    return nil
}
```

## Performance Considerations

### Cold Starts

First invocation after deploy or long idle → cold start:

**Optimize:**

1. **Minimize dependencies:**
```go
// ❌ Heavy global initialization
import _ "github.com/lib/pq"

var db = mustConnect()  // Blocks startup

// ✅ Lazy initialization
var (
    dbOnce sync.Once
    db     *sql.DB
)

func getDB() *sql.DB {
    dbOnce.Do(func() {
        db, _ = sql.Open("postgres", os.Getenv("DATABASE_URL"))
    })
    return db
}
```

2. **Use ARM64:**
```yaml
deploy:
  arch: arm64  # Faster, cheaper
```

3. **Right-size memory:**
```yaml
schedules:
  generate-daily-report:
    memory: 512  # More memory = more CPU
```

### Long-Running Tasks

For tasks > 15 minutes:

**Option 1: Chunk work**
```go
func processLargeDataset(ctx context.Context) error {
    offset := 0
    limit := 1000

    for {
        batch, err := db.GetBatch(ctx, offset, limit)
        if err != nil {
            return err
        }

        if len(batch) == 0 {
            break
        }

        // Process batch...
        offset += limit

        // Check deadline
        if deadline, ok := ctx.Deadline(); ok && time.Until(deadline) < 1*time.Minute {
            log.Println("Approaching deadline, will resume next run")
            return saveCheckpoint(ctx, offset)
        }
    }

    return nil
}
```

**Option 2: Fan out to queue**
```go
func fanOutWork(ctx context.Context) error {
    // Scheduled job splits work into queue messages
    items, err := db.GetItemsToProcess(ctx)
    if err != nil {
        return err
    }

    // Enqueue for parallel processing
    for _, item := range items {
        queue.Enqueue(ctx, "process-item", item)
    }

    log.Printf("Enqueued %d items for processing", len(items))
    return nil
}
```

## Cost Optimization

### Pricing Model

- **EventBridge invocations:** $1.00 per 1M invocations (first 14M free)
- **Lambda invocations:** $0.20 per 1M invocations
- **Lambda duration:** $0.0000166667 per GB-second (ARM64)

### Cost Examples

**Scenario: Hourly job (24/day, 720/month)**
- EventBridge: Free (< 14M)
- Lambda invocations: $0.00 (< 1M)
- Lambda duration (5s, 512MB): 1.88 GB-s = **$0.03/month**

**Scenario: Every minute job (43,200/month)**
- EventBridge: Free
- Lambda invocations: $0.01
- Lambda duration (1s, 256MB): 11K GB-s = **$0.18/month**
- **Total: ~$0.19/month**

### Optimization Tips

1. **Use appropriate frequency** - Don't poll unnecessarily
2. **Use ARM64** - 20% cheaper
3. **Optimize handler** - Reduce execution time
4. **Consider queues** - For high-frequency polling, use SQS instead

## Troubleshooting

### Issue: Schedule not triggering

**Check:**

1. EventBridge rule is enabled:
```bash
aws events describe-rule --name myapp-generate-daily-report
```

2. Lambda has EventBridge permissions:
```bash
aws lambda get-policy --function-name myapp-generate-daily-report
```

3. Rule target is configured:
```bash
aws events list-targets-by-rule --rule myapp-generate-daily-report
```

### Issue: Schedule triggering at wrong time

**Causes:**
- Cron expression in wrong timezone (EventBridge uses UTC)
- Daylight saving time confusion

**Solution:**
```go
// ❌ BAD: "Run at 2 AM local time"
app.RegisterScheduled("0 2 * * ? *", handler)  // Always 2 AM UTC!

// ✅ GOOD: Calculate UTC time
// If local is EST (UTC-5), 2 AM EST = 7 AM UTC
app.RegisterScheduled("0 7 * * ? *", handler)
```

### Issue: Execution taking too long

**Check CloudWatch Logs:**
```bash
aws logs tail /aws/lambda/myapp-generate-daily-report --follow
```

**Solutions:**
1. Increase timeout:
```yaml
schedules:
  generate-daily-report:
    timeout: 600  # 10 minutes
```

2. Chunk work (see Long-Running Tasks above)
3. Optimize slow queries/external calls

### Issue: Schedule executing multiple times

**Causes:**
- EventBridge retry after timeout
- Multiple rules with same schedule

**Check for duplicate rules:**
```bash
aws events list-rules --name-prefix myapp-generate-daily-report
```

**Add idempotency (see Idempotency section above)**
