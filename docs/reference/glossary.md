# Glossary

Quick reference for Transire-specific terms and concepts.

---

## A

### App

The main Transire application instance created with `transire.New()`. All handlers register with the app.

```go
app := transire.New()
```

See: [Hello World Tutorial](../learn/tutorials/01-hello-world.md)

---

### AST (Abstract Syntax Tree)

Go's code representation used by `transire gen` to analyze your code at build time. Enables type-safe manifest generation without runtime reflection.

See: [Core Concepts](../intro/concepts.md#build-time-manifest)

---

## B

### Batch Processing

Processing multiple queue messages together for efficiency. Default batch size is 10.

```go
func handler(ctx context.Context, orders []Order) error {
    // Process all orders in batch
    for _, order := range orders {
        process(order)
    }
    return nil
}
```

See: [Queue API Reference](sdk/queue-api/)

---

### Build-Time Manifest

JSON file (`transire_manifest.json`) generated by `transire gen` that describes all routes, queues, schedules, and dependencies. Used to generate infrastructure.

See: [Manifest Schema](manifest-schema.md)

---

## C

### Chi Router

Internal HTTP router used by Transire. Supports path parameters like `{id}` and `{path+}`. Not exposed in public API.

See: [HTTP API Reference](sdk/http-api/)

---

### Cloud Mode

When your Transire app runs on cloud infrastructure (Lambda, SQS, EventBridge). Opposite of Local Mode.

See: [Local vs Cloud Guide](../guides/local-vs-cloud/)

---

### Context

Go's `context.Context` passed to handlers for cancellation, timeouts, and request-scoped values.

```go
func handler(ctx context.Context, req *Request) error {
    // Check if request was cancelled
    if ctx.Done() != nil {
        return ctx.Err()
    }
    return nil
}
```

---

### CRUD

Create, Read, Update, Delete - the four basic operations for persistent storage.

See: [REST API Tutorial](../learn/tutorials/02-rest-api.md)

---

## D

### Dead Letter Queue (DLQ)

Queue where failed messages go after exceeding `max_receive_count`. Used for debugging and manual intervention.

See: [Queue Troubleshooting](../guides/troubleshooting/queue-issues/)

---

### Dependency Injection (DI)

Pattern for providing services to handlers without global variables. Transire supports singleton and request-scoped services.

```go
transire.Provide(func() (*DB, error) {
    return connectDB()
})
```

See: [DI Patterns Guide](../guides/di-patterns/)

---

## E

### Enqueue

Adding a message to a queue for asynchronous processing.

```go
app.Enqueue(ctx, "process-orders", order)
```

See: [Queue API Reference](sdk/queue-api/)

---

### EventBridge

AWS service that triggers scheduled Lambda functions. Used for `app.Schedule()` in cloud mode.

See: [AWS Schedules](../plugins/cloud/aws/schedules/)

---

## G

### Graceful Shutdown

Properly finishing in-progress requests before stopping the server. Default timeout is 30 seconds.

See: [Runtime Guide](../guides/development/local-development/)

---

## H

### Handler

Function that processes HTTP requests, queue messages, or scheduled triggers.

**Types:**
- HTTP: `func(w http.ResponseWriter, r *http.Request)`
- Queue: `func(ctx context.Context, msgs []T) error`
- Scheduled: `func(ctx context.Context) error`

See: [Core Concepts](../intro/concepts/)

---

### Hot Reload

Automatically restarting the server when code changes. Enabled with `transire run --watch`.

See: [Development Guide](../guides/development/hot-reload/)

---

## I

### IAM (Identity and Access Management)

AWS service for permissions. Transire generates least-privilege IAM policies automatically.

See: [AWS Permissions](../plugins/cloud/aws/permissions/)

---

### Idempotency

Property where repeating an operation produces the same result. Important for queue handlers and scheduled jobs.

See: [Idempotency Guide](../guides/idempotency/)

---

## L

### Lambda

AWS serverless compute service. Transire deploys handlers as Lambda functions.

See: [AWS Deployment](../plugins/cloud/aws/deployment/)

---

### Local Mode

Running your Transire app on your development machine with in-memory emulation of cloud services.

```bash
transire run
```

See: [Local vs Cloud Guide](../guides/local-vs-cloud/)

---

## M

### Manifest

See: **Build-Time Manifest**

---

### Middleware

Function that wraps handlers to add cross-cutting functionality (auth, logging, CORS, etc.).

```go
func authMiddleware(next http.Handler) http.Handler {
    return http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
        // Check auth
        if !isAuthed(r) {
            w.WriteHeader(401)
            return
        }
        next.ServeHTTP(w, r)
    })
}
```

See: [Middleware Patterns](../guides/middleware-patterns/)

---

## O

### OpenTofu

Open-source infrastructure-as-code tool (Terraform-compatible). Transire generates OpenTofu configuration for deployment.

See: [OpenTofu Guide](../plugins/iac/opentofu/)

---

## P

### Partial Batch Failure

When some messages in a batch succeed and others fail. Use `BatchResult` to report which messages failed.

```go
br := transire.NewBatchResult(len(msgs))
for i, msg := range msgs {
    if err := process(msg); err != nil {
        br.Fail(i, err)
    }
}
return br.ToCloudPartialBatchResponse()
```

See: [Queue API Reference](sdk/queue-api/#partial-batch-failures)

---

### Provider

Pluggable component that implements cloud-specific, IaC-specific, or CI-specific behavior.

**Types:**
- Cloud Provider (AWS, GCP, Azure)
- IaC Provider (OpenTofu, Pulumi)
- CI Provider (GitHub Actions, GitLab CI)

See: [Plugin Architecture](../plugins/cloud/overview/)

---

## Q

### Queue

Asynchronous message queue for processing work outside the HTTP request/response cycle.

```go
// Producer
app.Enqueue(ctx, "process-orders", order)

// Consumer
app.RegisterQueue("process-orders", processOrders)
```

See: [Queue API Reference](sdk/queue-api/)

---

### Queue Key

Unique identifier for a queue, used in both `Enqueue()` and `Queue()` registration.

```go
app.RegisterQueue("my-queue-key", handler)
app.Enqueue(ctx, "my-queue-key", message)
```

---

## R

### Registration

Declaring handlers at application startup.

```go
app.GET("/path", handler)        // HTTP registration
app.RegisterQueue("key", handler)        // Queue registration
app.Schedule("key", "cron", handler) // Schedule registration
```

See: [Core Concepts](../intro/concepts/#registration-patterns)

---

### Request-Scoped

Service created once per request/invocation. Cleaned up after request completes.

```go
transire.ProvideRequest(func(ctx context.Context, r *http.Request) (*RequestID, error) {
    return &RequestID{ID: generateID()}, nil
})
```

See: [DI Patterns](../guides/di-patterns/#request-scoped-services)

---

## S

### Scheduled Job

Function that runs on a fixed schedule (cron-style).

```go
app.Schedule("daily-report", "@daily 09:00", generateReport)
```

See: [Schedule API Reference](sdk/schedule-api/)

---

### Shorthand Schedule

Convenient syntax for common schedules:
- `@hourly` - Every hour
- `@daily` - Every 24 hours
- `@daily HH:MM` - Daily at specific time

See: [Schedule API Reference](sdk/schedule-api/#shorthand-syntax)

---

### Singleton

Service created once per process (local) or cold start (cloud). Shared across all requests.

```go
transire.Provide(func() (*DB, error) {
    return connectDB() // Called once
})
```

See: [DI Patterns](../guides/di-patterns/#singleton-services)

---

### SQS (Simple Queue Service)

AWS message queue service. Transire uses SQS for `app.RegisterQueue()` in cloud mode.

See: [AWS Queues](../plugins/cloud/aws/queues/)

---

## T

### Type Safety

Compile-time guarantee that queue messages match handler types. Enforced by `transire gen` and runtime checks.

```go
type Order struct { ID string }

// Type-safe: T is Order
app.RegisterQueue("orders", func(ctx context.Context, orders []Order) error {
    return nil
})
```

See: [Core Concepts](../intro/concepts/#type-safety)

---

## U

### URL Parameter

Dynamic path segment in routes, extracted with `transire.URLParam()`.

```go
app.GET("/orders/{id}", func(w http.ResponseWriter, r *http.Request) {
    id := transire.URLParam(r, "id")
    // ...
})
```

See: [HTTP API Reference](sdk/http-api/#url-parameters)

---

## V

### Validation

Checking input for correctness before processing.

```go
if req.Email == "" {
    response.BadRequest(w, "email is required")
    return
}
```

See: [REST API Tutorial](../learn/tutorials/02-rest-api/#step-6-implement-create-order-with-validation)

---

### Visibility Timeout

Time a message is hidden from other consumers after being received. Default: 30 seconds.

See: [Queue Configuration](config-schema/#queues)

---

## W

### Workspace

OpenTofu workspace for managing multiple environments (dev, staging, prod).

```bash
transire deploy --environment=dev    # Uses 'dev' workspace
transire deploy --environment=prod   # Uses 'prod' workspace
```

See: [Workspaces Guide](../plugins/iac/opentofu/workspaces/)
